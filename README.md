# ⚾ Hitting Count

Python과 `pygame-ce` 라이브러리를 활용하여 개발한 **탑다운 시점 야구 타격 게임**

타이밍 게이지에 맞춰 스윙하고, 안타·홈런·볼넷·수비 플레이를 즐기는 것이 목표.
**1인 Hitting Challenge**와 **2인 투수 vs 타자 대전** 두 가지 모드를 제공하며, 라인스코어 전광판, 주자·아웃·볼넷 규칙, 병살·희생플라이·끝내기, BEST PLAYER 등 실제 야구에 가까운 연출을 구현.

---

## 🎯 게임 소개

**Hitting Count**는 Python과 `pygame-ce`로 만든 2D 야구 타격 게임

하늘에서 내려다본 부채꼴 야구장 위에서 타이밍에 맞춰 스윙하고, 내야·외야 수비, 송구 애니메이션, 결과 배너, 이닝교대, 경기 종료 화면까지 한 화면에서 진행.

- **1인 모드**: CPU 투수와 대결하며 라운드별 목표 점수를 달성하는 Hitting Challenge
- **2인 모드**: 한 명은 구종 선택(투수), 한 명은 스페이스바 타격(타자) — 9회 정규 + 최대 12회 연장 대전

## ✨ 주요 기능

### 🎮 2가지 게임 모드

| 모드 | 설명 |
|------|------|
| **1인 게임 (Hitting Challenge)** | 제한 아웃 안에 누적 목표 점수 달성, 라운드 클리어 시 난이도 상승 |
| **2인 게임 (LINEUP)** | 9회 정규, 동점 시 최대 12회까지 연장, 12회에도 동점이면 무승부 / 홈팀 끝내기 승리 |

### ⏱ 타이밍 게이지 타격

스페이스바로 게이지를 멈추면 타구 품질이 결정.

| 구간 | 범위 | 결과 |
|------|------|------|
| 파랑 | 0~58% | 헛스윙 → 스트라이크 |
| 초록 (HIT) | 58~72% | 기본 컨택·안타 |
| 주황 | 72~82% | 강한 컨택·장타 |
| 빨강 | 82~85% | 최강·홈런 노리기 (가장 좁음) |
| 노랑 | 85~100% | 늦은 스윙·약한 타구 |

구속이 빠를수록 게이지도 빨라짐. (패스트볼 > 슬라이더 > 커브)

### ⚾ 구종 & 구속 (km/h)

| 구종 | 구속 범위 | 투구 키 (2인) |
|------|-----------|---------------|
| 패스트볼 | 145~153 | A팀 `1` / B팀 `8` |
| 슬라이더 | 125~132 | A팀 `2` / B팀 `9` |
| 커브 | 112~123 | A팀 `3` / B팀 `0` |

같은 구종이라도 매 투구마다 구속이 조금씩 달라짐.

### 🏃 주자·볼넷·수비 규칙

- **볼넷**: 포스 진루, 만루 볼넷은 **밀어내기** (+1득점)
- **고의사구**: 좌측 "투수 기록" 표시 아래 「고의사구」 버튼, 누르면 구종 선택 없이 곧장 볼넷 처리(정식 볼넷과 같은 기록)
- **사구(몸에 맞는 공)**: 아주 가끔(한 경기 1~2번꼴) 나오며, 카운트와 상관없이 투수가 실제로 공을 던지는 순간에만 판정(진루 규칙은 볼넷과 동일). 타자 기록의 "볼넷"엔 안 섞이고, 투수 기록의 "4사구"엔 볼넷과 합산되어 잡힘
- **병살타**: 2아웃, 만루 병살 시 3루 득점 (3아웃 이닝 종료 시 그 플레이 득점 무효)
- **희생플라이·태그업**: 2아웃 전 3루·2루 진루
- **2·3루만 있을 때 1루 송구**: 주자 제자리
- **1루 주자 + 2루 포스 아웃**: 3루 주자 홈인 가능
- **실책**: 내야 땅볼 처리 중 확률 발생(투수·1루수·2루수·유격수·3루수 5명 누구에게나 나올 수 있음), 배너엔 수비수 이름 없이 "실책"으로만 간단히 표시됨. 실책으로 출루한 주자의 득점은 투수 자책점에서 제외
- **번트 (`Shift`)**: 타격 중 Shift로 번트 시도 — 원정 공격은 왼쪽 Shift, 홈 공격은 오른쪽 Shift(1인 모드는 둘 다). 게이지 파랑 구간에서 누르면 헛스윙 스트라이크. 번트는 3루수·1루수가 주로 잡고(투수는 덜함), 1루수가 나오면 2루수가 1루를, 3루수가 나오면 1루수가 1루를 지키고(유격수는 2루에 주자가 있을 때만 3루, 주자가 1루뿐이면 2루를 커버하고 주자가 없으면 제자리) 내야수가 같이 움직인다. 나머지 수비수도 안타 때처럼 조금씩 반응해 움직인다(우익수는 1루 뒤 백업, 좌·중견수는 살짝 전진). 1루 아웃일 땐 주자가 공보다 확실히 늦게, 세이프일 땐 먼저 1루에 닿는다. 결과는 파울 / **번트 안타** / **실책**(번트 처리 내야수) / 아웃이며, 주자가 있으면 아웃이 **희생번트**(타자 아웃·모든 주자 한 베이스 진루, 타수 미포함). 2인 모드 2아웃이면 진루 없는 번트 아웃. 주자 없을 때 기습 번트는 번트 안타(약 10%, 드묾)나 실책이 나올 수 있고, 번트 파울은 스트라이크(2스트라이크에서는 **삼진**). 1인 모드는 번트 점수 없음 · 번트 안타 30점 · 번트로 득점하면 득점당 +50점
- **파울**: 타구 세기·각도에 따라 짧은 파울팁·포수 뒤 파울부터 관중석 파울, 파울 폴대를 넘길 뻔한 장외성 파울까지 거리가 다양하게 나옴

### 📊 1인 모드 — Hitting Challenge

| 항목 | 내용 |
|------|------|
| 안타 점수 | 1루타 30 / 2루타 50 / 3루타 70 / 홈런 100 |
| 타점 보너스 | 득점 1점당 +50 |
| 1라운드 목표 | 300점 (누적) |
| 라운드 상승 | +350 → +400 → +450 … (상승폭 매 라운드 +50, 최대 +650) |
| 시작 아웃 | 8개 (3라운드 클리어마다 1개 감소, 최소 5) |

### 🏆 2인 모드 — 정규 9회 + 연장

- 정규 **9회**까지 진행, 9회 종료 시 동점이면 **연장전**
- 연장은 **최대 12회**까지, 12회에도 동점이면 **무승부**
- 9회(또는 연장) 초 후 홈팀이 앞서면 **그 회말 생략·즉시 종료**
- 회말 홈팀이 1점이라도 앞서면 **끝내기 승리**
- 경기 종료 후 **BEST PLAYER** (승리팀 MVP) 표시
- **투수 교체**: 구종 선택 패널의 「교체」 버튼(다음 투구 전에만 가능), 교체 전/후 투수 기록 별도 집계
- **대타**: 타석 기록 표시 아래 「대타」 버튼(다음 투구 전에만 가능), 교체 전/후 타자 기록 별도 집계

### 📋 경기 기록

경기 종료 후 **기록** 버튼을 누르면 상단 탭에서 타자 기록 / 투수 기록을 전환해서 볼 수 있음.

| 구분 | 표시 항목 |
|------|-----------|
| 타자 | 타순 · 이름 · 타수 · 득점 · 안타 · 타점 · 홈런 · 볼넷 · 삼진 · 타율 |
| 투수 | 이름 · 이닝 · 피안타 · 실점 · 자책 · 4사구 · 삼진 · 피홈런 · 타자 · 타수 · 평균자책점 · (승/패/세이브/홀드) |

- 대타·교체 투수는 같은 타순/팀 아래 **별도 줄**로 표시되어 교체 전/후 기록이 섞이지 않음.
- 투수 기록 맨 끝 칸에는 **승/패/세이브/홀드**가 해당되는 투수에게만 표시(해당 없으면 빈칸).
- 평균자책점은 **자책점 기준** — 실책으로 출루한 주자의 득점은 제외하고, 구원투수가 승계주자를 실점시키면 그 주자를 내보낸 **원래 투수의 자책**으로 잡힘. 승/패는 아래 기준으로 판정.
- **승리투수**: 팀이 마지막으로 리드를 잡은 순간의 투수(동점이 되면 리드가 초기화되어, 다시 앞서는 순간의 투수가 승). 선발투수는 5이닝(15아웃) 미만이면 자격이 없고 가장 잘 던진 구원투수가 승
- **패전투수**: 결승점(마지막으로 리드를 내준 득점)을 허용한 책임 투수(승계주자면 그 주자를 내보낸 투수)
- **세이브**: 경기를 끝낸 구원투수(승리투수 제외)가 ①3점차 이내 등판 후 1이닝 이상, ②동점 주자가 루상·타석·대기타석에 있는 상황에서 등판, ③3이닝 이상 중 하나를 충족
- **홀드**: 세이브 상황(3점차 이내 또는 동점 주자 상황)에 등판해 1아웃 이상 잡고 리드를 지킨 채 교체됨

### ⏸ 일시정지

- 우하단 **일시정지** 버튼 또는 `ESC`
- **계속하기** / **라인업**(2인 모드, 이름·좌우타 수정 후 이어서) / **그만하기** 선택

![투수 교체](images/06b_pitcher_sub.png)

- 교체 전 투수의 기록은 그대로 남고, 교체 이후 기록은 새 투수 몫으로 따로 쌓임

### 경기 중 라인업 수정

![경기 중 라인업 수정](images/08b_lineup_resume.png)

- 일시정지에서 **라인업**을 누르면 지금 라인업(이름·좌우타·팀명·현재 투수)을 고칠 수 있음
- **계속하기**로 돌아가면 점수·이닝·기록은 그대로 두고 고친 내용만 반영해 이어서 진행
- **취소**는 수정 없이 바로 복귀
- **이름을 바꾸면 대타·투수 교체와 똑같이 취급**: 그 순간까지 쌓인 기록은 이전 선수 몫으로 남고, 이후 타석/이닝은 새 선수가 0부터 새로 쌓음(경기 종료 후 기록표에도 둘이 별도 줄로 표시)
- 이름을 안 바꾸고 좌우타·포지션만 고치면 같은 선수로 보고 기록이 안 갈라짐(포지션은 이 화면에서 경기 중에도 바꿀 수 있음)
- 바뀐 이름이 그 팀에서 이미 썼던 이름이면 "이미 출전했던 선수 명단입니다. 다른 선수입니까?" 확인 창이 뜨고, **아니오**를 누르면 반영 없이 라인업 화면에 그대로 남음
- 이름 입력 중이어도 **엔터** 키로 바로 계속하기 가능

### 결과 배너 — 홈런

![홈런 결과](images/09_result_homerun.png)

### 결과 배너 — 삼진

![삼진](images/11_result_strikeout.png)

- 안 치고 볼 때 **STRIKE (S1)** / **BALL (B1)** 카운트 표시

### 경기를 끝내는 마지막 아웃

![마지막 아웃](images/11b_result_last_out.png)
![경기 종료](images/11c_result_gameover.png)

- 그 아웃으로 경기가 끝나면 실제 아웃 결과(**"STRIKE OUT"**, **"땅볼 아웃 (유격수)"** 등) 배너를 먼저 보여준 뒤, 곧바로 결과 화면으로 넘어가지 않고 **"경기 종료"**(무승부면 "경기 종료\n무승부") 배너를 한 박자 더 띄우고 나서 결과 화면으로 이동
- 득점으로 끝나는 **끝내기 승리**는 "끝내기 승리" 배너 자체가 이미 결과를 알려주므로 이 배너를 또 띄우지 않음

### 타자 기록표

![타자 기록](images/17b_boxscore.png)

- 경기 종료 후 **기록** 버튼 클릭 시 양팀 9명 타순·이름·타수·**득점**·안타·타점·홈런·볼넷·삼진·타율 표시
- 상단 탭으로 **투수 기록**으로도 전환 가능
- 대타·교체 투수는 같은 타순/팀 아래 별도 줄로 표시
- 각 팀 맨 마지막 줄에 **팀 합계**(같은 항목 그대로 합산) 표시
- 대타가 많이 들어와 표가 화면보다 길어지면 **마우스 휠 또는 ↑↓**로 스크롤

### 투수 기록표

![투수 기록](images/17c_pitcher_boxscore.png)

- 이름·이닝·피안타·실점·자책·4사구·삼진·피홈런·타자·타수·평균자책점 순으로 표시
- 맨 끝 칸에는 **승/패/세이브/홀드**가 해당되는 투수에게만 표시(해당 없으면 빈칸)
- 각 팀 맨 마지막 줄에 **팀 합계**(같은 항목 그대로 합산) 표시
- 칸 수가 많아 두 팀을 위아래로 쌓아서 화면 폭을 최대한 활용
- 투수 교체가 많아 표가 화면보다 길어지면 **마우스 휠 또는 ↑↓**로 스크롤

## 🧠 모듈 구조

### `App` (`app.py`)

게임 루프와 화면(씬) 전환을 담당.

- 메뉴 / 라인업 / 플레이 / 경기 종료 / 게임 설명 / 개발정보
- 입력 처리 · 렌더링 · 씬 전환

### `LiveGame` (`gamestate.py`)

경기 상태와 야구 규칙을 담당.

- 라인스코어 · 주자(개인 신원 포함) · 아웃 · 팀/개인 득점
- 볼넷·병살·희생플라이·끝내기 판정
- 대타·투수 교체 시 선수별 기록 분리 집계, 자책점(비자책 실점 판정) 계산
- 1인 챌린지 점수·라운드·아웃
- 타구 물리·수비 판정 (`resolve_batted_ball`)

### `field.py`

탑다운 야구장 렌더링과 좌표 변환을 담당.

- 부채꼴 그라운드 · 관중석 · 담장 · 파울 폴
- 수비수·타자·주자·공 애니메이션

### `ui.py` / `assets.py`

- 버튼 · 텍스트 입력 · 한글 폰트
- 타이틀 실루엣 이미지

### `config.py`

색상 · 규칙 상수 · 기본 라인업 · 버전 정보

## 📌 구현 기능

- 탑다운 부채꼴 야구장 · 그랜드스탠드형 관중석 · 파울 폴
- 1인 Hitting Challenge (라운드·목표·아웃)
- 2인 정규 9회 + 최대 12회 연장 대전 (끝내기·무승부)
- 타이밍 게이지 타격 (5구간 파워)
- 3구종 · 랜덤 구속 · 구속별 게이지 속도
- 라인스코어 전광판 (R/H/E/B)
- 볼넷 · 밀어내기 · 삼진 · 파울
- 내야/외야 수비 · 송구 · 병살 · 희생플라이 · **내야 직선타 아웃**(유격수·2루수·1루수·3루수)
- 주자·수비·타구 애니메이션
- 결과 배너 (홈런·적시타·밀어내기 등)
- 이닝교대 · 라운드 클리어 연출
- 일시정지 메뉴
- **경기를 끝내는 마지막 아웃**: 아웃 결과 → "경기 종료" 순서로 배너 표시 후 결과 화면 이동(끝내기 승리는 예외)
- **경기 종료 후 "기록" 버튼 → 타자 기록 / 투수 기록 탭**
  - 타자: 타순·이름·타수·득점·안타·타점·홈런·볼넷·삼진·타율
  - 투수: 이름·이닝·피안타·실점·자책·4사구·삼진·피홈런·타자·타수·평균자책점(자책점 기준) · 승/패/세이브/홀드(해당자만 표시)
  - 표가 화면보다 길어지면 마우스 휠/↑↓로 스크롤
- **대타 · 투수 교체**: 교체 전/후 선수 기록을 각자 분리 집계(승계주자 실점은 원래 투수 자책)
- **동명이인 재출전 확인**: 로스터가 없는 게임이라, 대타·투수교체·라인업 수정에서 그 팀이 이미 썼던 이름을 다시 입력하면 확인 창이 뜸
- **고의사구 버튼**: 구종 선택 없이 곧장 볼넷 처리
- **번트**: Shift 키 · 번트 안타/실책/희생번트/번트 파울 삼진 (1인 모드는 안타 30점·득점 +50점)
- **사구(몸에 맞는 공)**: 가끔 발생, 카운트와 상관없이 투수가 실제로 공을 던지는 순간에만 판정
- BEST PLAYER · 경기 종료 화면
- 게임 설명 · 개발정보 화면
- **원정/홈 라인업 독립 설정** · 선발투수(좌투/우투) · 한글 이름 입력 · `Tab` 입력창 이동
- **라인업 화면 "홈/원정" 버튼**: 입력해둔 원정·홈 라인업을 통째로 맞바꾸기
- 이름 입력창에서 키(백스페이스 등)를 꾹 누르면 연속 입력/삭제(키 반복)
